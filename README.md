# Do4Love Post Helper

An AI-assisted tool that helps small sustainability-driven brand founders turn
event photos and rough notes into a reviewable photo selection and on-voice
captions that use only facts the founder provides.

## What the first working slice does
A user adds event photos, notes, a voice guide, and sample posts, then presses
Draft. The prototype shows suggested photos in order with reasons, set-aside
photos with reasons, and 2–3 captions with a facts panel that flags statements
not in the notes and highlights sustainability claims.

## Try it
[Replit link] — click "Use sample event," then Draft.

## AI status
**Intended AI:** a vision model tags and ranks photos and explains each pick; a
language model drafts captions in the brand's voice and checks their facts
against the notes. Nothing is identified by name and nothing posts automatically.
**Working now:** upload and thumbnails, input validation, flow from input to result.
**Simulated:** all photo picks, reasons, captions, and fact checks are
prewritten (generated beforehand with Claude from my real event and pasted in).
No live model, backend, or database. No API keys in this repo.
